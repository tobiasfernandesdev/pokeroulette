# Créditos de áudio do Roleta Kanto

Os 30 arquivos usados pelo jogo ficam em `src/main/resources/assets/audio/`.
Foram convertidos de OGG para WAV PCM de 16 bits, mono e 22.050 Hz para o Java Sound.
As faixas em loop usam a duração integral do arquivo. A vinheta Hero Jingle usa
os primeiros 4 segundos com uma saída curta. O efeito `ataque.wav` foi encurtado
para 0,35 s para encaixar no feedback de combate.

## Música

O **8-Bit BGM Collection**, de **easyeye163**, autoriza uso e edição em jogos.
Sua licença é específica para os recursos e veda revenda, sublicenciamento ou
redistribuição como biblioteca de áudio, além de uso em NFT/blockchain sem
permissão. [Licença dos áudios](https://github.com/easyeye163/8bit-bgm-collection/blob/8fa4f407b92d7e841c6db6a53782bc8a8f43ba42/LICENSE-ASSETS.txt).

**Menu Music**, de **wipics**, foi importada do **Aozora Islands**, onde o arquivo
consta como CC0. [Créditos do repositório](https://github.com/tegnike/aozora-islands/blob/6dc06266c3263e93d8b8efd3d7e9a31b7db141f8/src/assets/audio/README.md).
